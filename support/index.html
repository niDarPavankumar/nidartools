Tool Help

Need help with a specific tool?

niDar Tools provides simple browser-based utilities for everyday image, PDF, calculator, QR and data-format tasks.

🖼️

Image Tools

For Image Resizer, Image Compressor, Image Format Converter, Image to PDF and Background Remover, make sure your browser supports the selected file type and that the file is fully loaded before processing.

📄

PDF Tools

When working with Word to PDF, PDF to Word or Image to PDF, allow the tool to finish processing before downloading the generated file.

🧮

Calculators

Enter the required values carefully and check the units shown beside each field. Construction, EMI, percentage and age calculations may depend on the values you provide.

🔳

QR & Data Tools

For QR Generator, Base64 Encoder/Decoder and JSON Formatter, check that the text or data you enter is complete before generating or formatting the result.

Troubleshooting

Something is not working?

Try these simple steps before reporting a problem.

1

Refresh the page

Reload the tool and try the operation again. A temporary browser issue can sometimes prevent a tool from completing.

2

Check your input

Make sure all required fields contain valid values and that the selected file or data is supported by the tool.

3

Try another browser

If the problem continues, try an updated version of Chrome, Firefox, Edge or another modern browser.

4

Contact support

If the issue remains, send us the tool name and a short description of what happened.

🐞

Reporting a bug?

To help us understand the problem faster, please include:

  • The name of the tool you were using.
  • The phone, tablet or computer you were using.
  • Your browser name and version, if known.
  • What you expected to happen.
  • What actually happened.

Privacy

Your privacy matters

Many niDar Tools are designed to perform processing directly in your browser. Depending on the tool and feature, files or information may be processed locally rather than uploaded to a server. Always check the individual tool's information and privacy details before using sensitive files.
